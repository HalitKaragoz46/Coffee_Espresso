A modern, responsive coffee shop website built with HTML, CSS, and JavaScript. Features a premium dark theme design with interactive elements and smooth animations.

# 🚀 Features
- Responsive Design - Mobile-first approach with perfect display across all devices
- Modern UI/UX - Dark theme with golden accents and smooth hover animations
- Interactive Elements - Dynamic buttons, image scaling, and transition effects
- E-commerce Ready - Product showcase with pricing and cart functionality
- Google Maps Integration - Embedded location map for contact section
- Blog Section - Content management area for marketing
- Social Media Integration - Links to all major social platforms

# 🛠️ Technologies Used
- HTML5 - Semantic markup structure
- CSS3 - Custom properties, Grid, Flexbox, animations
- JavaScript - Interactive functionality and mobile menu
- Font Awesome - Icon library
- Google Fonts - Roboto typography

# 📱 Sections
- Hero Section - Eye-catching banner with call-to-action
- About Us - Company story and coffee quality focus
- Menu - 10 coffee products with pricing
- Products - Featured items with star ratings
- Reviews - Customer testimonials
- Contact - Contact form and location map
- Blog - Latest news and updates
- Footer - Social links and site navigation

# 🎨 Design Features
- Premium dark color scheme (#010103, #13131a, #d3ad7f)
- Smooth scroll behavior and custom scrollbar
- Hover effects and scaling animations
- Mobile hamburger menu
- Responsive grid layouts

# 📊 Performance
- Optimized images and clean code structure
- SEO-friendly semantic HTML
- Fast loading with CDN integration
- Cross-browser compatibility
